# WHENCALENDAR — 요구사항

> 프로젝트 정의는 [01_프로젝트.md](01_프로젝트.md), 기술 결정은 [03_기술_스펙.md](03_기술_스펙.md). ID 체계와 문서 형식은 WHENNOTE `docs/02_요구사항.md`를 따른다. 2026-09-17 정의. 체크는 자동 테스트가 증명한 것만 — UI 항목은 실사용으로 확인한 뒤 체크한다.

**Core Value:** 몰입해도 시간을 잃지 않는다. 창을 열지 않아도, 보려고 하지 않아도, 다음 하나까지 얼마 남았는지 안다.

## v1 Requirements

### 오버레이 (OVL)

이 앱의 존재 이유다. 나머지 그룹은 전부 이걸 받쳐 준다.

- [ ] **OVL-01**: 화면 상단 가운데에 아일랜드가 상주한다. 프레임 없는 투명 창이고, 앱을 실행한 뒤 아무 설정 없이 바로 뜬다
- [x] **OVL-02**: 오버레이는 **전체화면 앱 위에** 뜬다. 전체화면 IDE·브라우저 영상·발표 화면에서 가려지지 않는다 — 2026-09-17 실측. `screen-saver` 레벨만으로는 가려졌고 1초 주기 `moveTop()`으로 해결([D-14](03_기술_스펙.md#d-14-z-order는-주기적으로-다시-잡는다)). 전체화면 앱이 뜬 직후 최대 1초는 가려지고, exclusive fullscreen은 범위 밖
- [ ] **OVL-03**: 오버레이는 **마우스 클릭을 통과시킨다.** 아일랜드 아래에 있는 창을 그대로 누를 수 있다
- [ ] **OVL-04**: 오버레이는 **포커스를 뺏지 않는다.** 뜨거나 펼쳐질 때 타이핑하던 창의 커서가 유지된다
- [x] **OVL-05**: 남은 시간에 따라 다섯 단계로 변한다 — 60분 초과: 링만(접힘) · 30분부터: 이름과 남은 시간이 펼쳐지기 시작 · 10분: 완전히 펼침 · 5분: 색이 붉어지고 번짐 · 1분: 테두리가 맥동. 어느 단계에서도 클릭을 요구하거나 화면을 가리지 않는다
- [ ] **OVL-06**: 링 게이지가 60분을 한 바퀴로 남은 양을 보여 준다. 60분 이상 남으면 꽉 찬 채로 멈춰 있다
- [ ] **OVL-07**: 오늘 남은 일정 개수가 점으로 보인다. 다음 하나만 색이 들어오고 나머지는 회색이다
- [x] **OVL-08**: 일정이 **진행 중**이면 색이 중립(청록)으로 바뀌고 "진행 중" 배지가 붙는다. 링은 끝날 때까지를 센다
- [x] **OVL-09**: 진행 중인 일정이 **끝나기 5분 전**이면 색이 다시 들어오고 "곧 종료"로 바뀐다. 설정에서 끌 수 있다
- [ ] **OVL-10**: 오늘 남은 일정이 없으면 오버레이가 조용히 숨는다. 마우스를 올리면 다시 보인다
- [ ] **OVL-11**: 아일랜드에 **마우스를 올리면** 시간과 무관하게 펼쳐지고, 자동 펼침에는 없는 **그 다음 일정**까지 따라 나온다. 마우스를 빼면 원래 상태로 돌아간다
- [ ] **OVL-12**: 설정에서 펼침 시작 시각, 완전 펼침 시각, 링 크기(16·20·26px), 위치, 대상 모니터를 바꾼다. 값을 바꾸면 설정 화면의 미리보기가 즉시 같이 바뀐다
- [ ] **OVL-13**: 본체 창에서 <kbd>O</kbd>로 오버레이를 잠시 끈다. 발표·녹화 중에 쓴다
- [ ] **OVL-14**: 시스템 잠금·절전에서 돌아왔을 때 오버레이가 현재 시각 기준으로 즉시 올바른 상태를 보여 준다

### 일정 소스·구독 (SUB)

- [ ] **SUB-01**: `.ics` URL을 등록하면 일정을 읽어 온다. **읽기 전용이고 OAuth·로그인이 필요 없다.** 구글 캘린더의 비공개 iCal 주소를 붙여 쓴다
- [ ] **SUB-02**: 구독은 정해진 주기로 자동 갱신되고, <kbd>R</kbd>로 즉시 갱신한다. 마지막 갱신 시각이 보인다
- [ ] **SUB-03**: **구독 갱신이 실패해도 마지막에 받아온 일정은 지우지 않는다.** 네트워크가 끊겼다고 오늘 일정이 사라지면 안 된다
- [ ] **SUB-04**: 갱신 실패는 원인과 **다음에 할 행동**까지 화면에 적는다. "동기화 실패"로 끝내지 않는다
- [ ] **SUB-05**: 구독마다 색이 하나씩 붙는다. 추가할 때 자동 배정되고 <kbd>C</kbd>로 바꾼다. 색은 6종이며 배정 순서는 상태색(성공·경고·실패)과 같은 값을 뒤로 미룬다
- [ ] **SUB-06**: 구독을 <kbd>Space</kbd>로 켜고 끈다. 끄면 일정이 화면에서 빠지되 구독 자체는 남는다
- [ ] **SUB-07**: `.ics`의 반복 규칙(RRULE)과 예외(EXDATE·RECURRENCE-ID)를 해석해 실제 날짜로 펼친다. 자체 반복 규칙을 만들지 않는다
- [ ] **SUB-08**: `.ics`의 타임존(TZID)을 해석한다. 해외 일정이 시각이 어긋난 채 들어오지 않는다

### 본체 창 (WIN)

- [ ] **WIN-01**: 전역 단축키로 본체 창을 열고 닫는다. 창 위치·크기를 기억한다 (WHENWORK `place.mjs` 승계)
- [ ] **WIN-02**: 탭은 오늘 · 주 · 월 · 구독 · 설정이고 <kbd>Tab</kbd>으로 돈다. 탭에 건수 배지가 붙는다
- [ ] **WIN-03**: **오늘** 탭은 시간축 목록이다. 지나간 일정은 흐려지고, 지금 시각에 선이 그어지고, 진행 중인 것과 다음 하나가 구분된다
- [ ] **WIN-04**: **주** 탭은 요일별 밀도 띠 + 날짜별 세로 목록이다. 격자를 쓰지 않는다 — 키보드로 훑는 데는 목록이 빠르다
- [ ] **WIN-05**: **월** 탭은 격자다. 칸마다 일정을 최대 2건 + `+N`으로 적고, 고른 날의 전체 목록은 아래 한 줄에 펼친다. <kbd>hjkl</kbd>로 날짜를 옮긴다
- [ ] **WIN-06**: 여러 날에 걸친 일정은 월 격자에서 **칸 위를 가로지른다.** 주 경계를 넘으면 두 조각으로 나뉘고 잘린 쪽 모서리로 이어짐을 표시한다. 레인은 두 줄까지 쌓고 그 뒤는 `+N`으로 접는다
- [ ] **WIN-07**: 마우스 없이 전부 조작된다. <kbd>?</kbd>로 전체 키맵을 본다. 키 글자의 뜻은 WHENWORK와 같다(<kbd>E</kbd> 제목, <kbd>X</kbd> 삭제, <kbd>U</kbd> 되돌리기, <kbd>/</kbd> 검색)
- [ ] **WIN-08**: 창을 닫아도 앱은 트레이에 남는다. 오버레이는 계속 동작한다
- [ ] **WIN-09**: 기본 창 크기는 960×640, 최소 760×540이다

### 일정 등록·편집 (EV)

- [ ] **EV-01**: <kbd>N</kbd>으로 한 줄 입력을 받아 일정을 만든다. `내일 15:00 치과 1시간` 같은 표현을 **로컬 규칙 파서**가 해석한다. 네트워크·API 키가 필요 없다
- [ ] **EV-02**: 해석 결과를 **등록 전에 보여 주고** <kbd>Enter</kbd>를 받는다. 자동으로 넣지 않는다. 애매한 부분("3시를 오후로 봤습니다")은 눈에 띄게 표시하고 그 자리에서 뒤집을 수 있다
- [ ] **EV-03**: 해석에 실패하면 거절하지 않고 구조화 입력(날짜·시각·제목)으로 넘어간다. 입력한 글자는 제목으로 남는다
- [ ] **EV-04**: <kbd>Enter</kbd>로 상세를 연다. 상세는 목록을 밀어내지 않고 오른쪽에 붙는다
- [ ] **EV-05**: 제목·날짜·시각·반복·알림·달력을 각각 한 글자 키로 고친다. **구독으로 들어온 일정은 읽기 전용**이고 그 사실이 화면에 드러난다
- [ ] **EV-06**: 삭제는 소프트 삭제이고 <kbd>U</kbd>로 되돌린다. 30일이 지난 것만 실제로 지워진다 (WHENWORK 삭제 규칙 승계)
- [ ] **EV-07**: 직접 등록한 반복 일정을 고칠 때 "이 하나만 / 이후 전부"를 묻는다. 예외는 RFC 5545 방식으로 저장한다
- [ ] **EV-08**: 일정마다 알림 시각(N분 전)을 둘 수 있다. 알림은 OS 알림이 아니라 오버레이 단계 변화로 표현하는 것이 기본이고, OS 알림은 설정에서 켠다

### 시간 찾기 (FIND)

- [ ] **FIND-01**: <kbd>G</kbd>로 빈 시간을 찾는다. 길이(30분·1시간·2시간·반나절)와 시간대(업무 시간·아무 때나)를 고르면 후보가 나온다
- [ ] **FIND-02**: 각 후보에 앞뒤 일정이 무엇인지와 그 사이 어디가 비는지가 함께 보인다
- [ ] **FIND-03**: <kbd>Enter</kbd>로 그 자리에 바로 일정을 만든다
- [ ] **FIND-04**: <kbd>Y</kbd>로 고른 후보들을 **클립보드에 복사**한다. 메일·메신저로 보내지 않는다 — 붙여넣는 것은 사람이 한다 (WHENMAIL "초안까지만" 승계)
- [ ] **FIND-05**: 복사되는 내용에 **일정 제목이 들어가지 않는다.** 빈 시간만 적는다. 상대에게 내 일정 내용이 새어 나가면 안 된다
- [ ] **FIND-06**: 복사 형식(목록·문장·표)과 말투(평어·높임)를 고른다

### 검색 (SRCH)

- [ ] **SRCH-01**: <kbd>/</kbd>로 검색한다. 부분 문자열과 한글 초성으로 찾는다 (WHENNOTE SRCH-01·02 승계)
- [ ] **SRCH-02**: **지난 일정도 찾는다.** 결과는 앞으로 올 것과 지난 것을 나눠 보여 준다 — 실제 쓰임은 "그 회의 언제였지"다
- [ ] **SRCH-03**: 일치한 글자가 강조된다

### 저장소 (STOR)

- [x] **STOR-01**: 앱은 외부 DB·컨테이너 없이 앱 데이터 폴더 안의 내장 저장소(단일 파일)에 일정·구독·설정을 저장한다 (WHENNOTE STOR-01 승계)
- [x] **STOR-02**: 저장소 스키마에 버전이 있고 업데이트 시 사용자 개입 없이 자동 마이그레이션된다. 이행 직전 자동 백업이 남는다 (WHENNOTE STOR-02 승계)
- [x] **STOR-03**: 자신보다 높은 스키마 버전의 DB를 만나면 쓰지 않고 안내한다. 손상된 DB는 지우지 않고 옆에 보관한다 (WHENWORK D-13·D-15 승계)
- [ ] **STOR-04**: 구독으로 받아온 일정과 직접 등록한 일정이 저장소에서 구분된다. 구독을 지우면 그 일정만 빠지고 직접 등록한 것은 남는다

### 내보내기·가져오기 (DATA)

- [ ] **DATA-01**: 설정에서 전체 데이터를 JSON 파일 하나로 내보낸다 (WHENNOTE DATA-01 승계)
- [ ] **DATA-02**: 내보낸 JSON을 다른 PC에서 가져오면 같은 상태로 복원된다. 왕복 테스트가 있다. 가져오기 직전 자동 백업된다
- [ ] **DATA-03**: 직접 등록한 일정을 `.ics` 파일로 내보낸다. 표준 형식이라 다른 캘린더가 읽는다

### 첫 실행·플랫폼 (PLAT)

- [ ] **PLAT-01**: 설치 후 첫 실행에 설정 화면 없이 오버레이가 뜬다. 구독이 없으면 무엇을 하면 되는지 한 화면으로 안내한다
- [ ] **PLAT-02**: 전역 단축키 등록이 실패하면(형제 앱과 충돌 포함) 알리고 설정에서 다시 지정한다. 바꾼 조합의 등록 성공 여부를 확인한다 (WHENNOTE PLAT-02 승계)
- [ ] **PLAT-03**: 설정에 로그인 시 자동 실행 토글이 있다
- [ ] **PLAT-04**: 멀티 모니터에서 주 모니터만 쓸지 전부 쓸지 고른다. 모니터 구성이 바뀌면 오버레이가 따라간다
- [ ] **PLAT-05**: 형제 앱 세 개와 같은 PC에서 동시에 실행돼도 트레이·단축키·데이터 폴더가 서로 간섭하지 않는다
- [ ] **PLAT-06**: OS 분기는 `main/platform/` 안에만 있다. 계약 테스트가 이를 지킨다 (WHENWORK 승계)

### 릴리스 (REL)

- [ ] **REL-01**: Windows NSIS 설치 파일이 electron-builder로 빌드된다
- [ ] **REL-02**: GitHub Actions가 태그 푸시 시 빌드해 Releases 드래프트에 올린다. 사람이 공개한다
- [ ] **REL-03**: 앱이 새 버전을 감지해 알리고 Windows는 종료 시 설치한다 (WHENWORK `update.mjs` 승계)
- [ ] **REL-04**: README에 설치·미서명 첫 실행 우회·단축키·데이터 위치가 있다
- [ ] **REL-05**: 패키징된 설치본에서 스모크 테스트가 통과한다. **오버레이가 전체화면 앱 위에 뜨는지를 설치본에서 확인한다**(OVL-02, `poc/verify-fullscreen.ps1`)

### 완료 판정 (DONE)

- [ ] **DONE-01**: 작성자가 2주 사용한 뒤 "몰입하다 일정을 놓치거나 늦은 날"이 0일이다

## v2 Requirements

- **NL-01**: 규칙 파서가 못 알아듣는 문장을 LLM으로 넘긴다. 설정에 키를 넣었을 때만 켜지고, 기본값은 규칙 파서 단독 ([03 §자연어](03_기술_스펙.md))
- **NL-02**: 클립보드·스크린샷에서 일정 제안 — 카톡·메일에서 복사한 문장을 읽어 일정 후보를 만든다
- **NL-03**: 음성 한 줄 입력 (whisper.cpp 로컬)
- **MAC-01**: macOS 지원 (메뉴바 상주, 전체화면 위 표시 검증 필요)
- **CAL-01**: 구독 달력에 쓰기 (OAuth가 필요해 보류)
- **TZ-01**: 타임존 전환 UI — 해외 미팅 시각을 현지·내 시각 양쪽으로
- **TRUST-01**: 코드 서명·공증
